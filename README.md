# ApexPlanet_Data_Analytics_Internship_Task-3
# 📊 Sales Performance & Customer Value Analytics Dashboard

Welcome to the **Task 3** project repository for the **ApexPlanet Data Analytics Virtual Internship**. This project delivers an end-to-end data analytics workflow—from raw data processing and KPI calculations in Python to an interactive, executive-ready Business Intelligence dashboard built in Microsoft Power BI.

---

## 📌 Executive Summary

This project analyzes sales performance across categories, regions, and customer segments to uncover key revenue drivers and growth opportunities. The final outcome is a three-page interactive Power BI dashboard designed for executive leadership, regional managers, and marketing teams to explore data dynamically and drive strategy.

---

## 🎯 Key Performance Indicators (KPIs)

* **Total Revenue:** **$139.40M** — Total sales revenue generated across the dataset.
* **Total Orders:** **992** — Total unique orders recorded.
* **Unique Customers:** **947** — Total individual customers identified.
* **Average Order Value (AOV):** **$140.52K** ($140,523.63) — Average revenue generated per order.
* **Average Spend per Customer:** **$147,201.10** — Average revenue contribution per unique customer.
* **Repeat Purchase Rate:** **5.49%** — Percentage of customers who placed more than one order.

---

## 🛠️ Tech Stack & Architecture

* **Core Language:** Python 3.x
* **Data Processing & Analytics:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Business Intelligence Tool:** Microsoft Power BI Desktop
* **Calculations & Data Modeling:** DAX (Data Analysis Expressions)
* **Development Tools:** VS Code, Jupyter Notebook
